# Education Evasion Modeling (Public Portfolio)

## Overview

This repository documents an end-to-end higher education evasion analysis workflow built with:

- public education census datasets
- SQL feature engineering
- Python econometric and ML modeling

The project reuses the same **public source tables** that were loaded in a corporate Market Intelligence pipeline (via Tableau Prep), but this portfolio contains only public logic and sanitized artifacts.

## Business Question

Which institutional characteristics are associated with higher student evasion rates in Brazilian higher education institutions (IES)?

## Data Scope

Main public datasets (already loaded in the source warehouse in the original project):

- IES institution-level census table
- IES course-level census table
- IGC quality indicator table

Time windows used in the modeling variants:

- baseline variant: 2022 only
- panel variant: 2021 and 2022

## Repository Structure

- `sql/`: core SQL transformations and validation checks
- `python/`: reproducible modeling pipeline (data pull, transforms, FE/RE, robust regressions, random forest)
- `docs/`: methodology and variable notes
- `data/`: local bronze/silver outputs generated from public MEC files

## Public MEC Consolidation (Outside Corporate)

To make this project reproducible in a non-corporate environment, use the local consolidator:

- Script: `python/consolidate_mec_public_data.py`
- Runbook: [docs/how_to_run_simple.md](docs/how_to_run_simple.md)

The script reads yearly MEC CSV files and IGC result files (CSV/XLS/XLSX) from your local downloads folder, excludes private/non-public files by naming rule, and generates standardized parquet datasets.

## SQL Flow

1. Build institution-year aggregates from course-level data
2. Build support tables (`poles` and lagged entrants for graduation success rate)
3. Build analytical view with dependent/independent variables
4. Run sample quality checks

See [docs/flow.md](docs/flow.md).

## Python Flow

1. Read analytical dataset from SQL view
2. Prepare panel index (`Cod_IES`, `NU_ANO_CENSO`)
3. Apply transformations for selected predictors
4. Fit model families:
   - pooled/robust regressions
   - fixed effects and random effects (PanelOLS / RandomEffects)
   - random forest benchmark
5. Export summary metrics to CSV

## Security and Sanitization

- No proprietary credentials are stored.
- No proprietary dashboards, prep flow files, or internal connection strings are included.
- Use environment variables for database connections.

## How To Run

Fast path (recommended):

1. Follow [docs/how_to_run_simple.md](docs/how_to_run_simple.md) to consolidate public MEC files locally.
2. Then execute the modeling pipeline.

Detailed modeling path:

1. Create the SQL objects in order from the `sql/` folder.
2. Configure environment variables:
   - `DB_DIALECT`
   - `DB_HOST`
   - `DB_PORT`
   - `DB_NAME`
   - `DB_USER`
   - `DB_PASSWORD`
3. Install dependencies:
   - `pip install -r requirements.txt`
4. Run:
   - `python python/modeling_pipeline.py`
